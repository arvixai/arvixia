ARVIX IA

Assistente de inteligência artificial da ARVIX.

Sobre

A ARVIX IA é uma assistente de inteligência artificial desenvolvida para responder perguntas e auxiliar os usuários de forma rápida, clara e inteligente.

Estrutura do projeto

frontend/ — interface da ARVIX IA

backend/ — servidor responsável pela comunicação com a IA

package.json — dependências e configurações do backend

README.md — documentação do projeto


Tecnologias

HTML

CSS

JavaScript

Node.js

Express

OpenAI API

GitHub Pages

Render


Como funciona

O frontend apresenta a interface do chat e envia as mensagens para o backend.

O backend processa as solicitações e se comunica com a API de inteligência artificial, retornando a resposta para o usuário.

Segurança

As chaves de API devem ser armazenadas em variáveis de ambiente e nunca devem ser colocadas diretamente no código público do GitHub.
